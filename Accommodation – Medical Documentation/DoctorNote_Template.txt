Physician's Note Template — Workplace Accommodation (OHRC)
For Dr. K. Sotoudeh — Bradford Health Care Centre

What this note must do (so the doctor doesn't need to know OHRC):
  1. Confirm a disability exists.
  2. State the functional limitations (commuting = trigger / relapse risk).
  3. State the accommodation needed (remote work / reduced in-office, as required).
  4. State duration (permanent or reviewable).
Avoid: treatment details, medication, history — HR only needs functional information.
